+# TimeSpace Shadow Implementation Plan
+
+> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.
+
+**Goal:** Implement a research-only, point-in-time sidecar that measures whether early August Alpha flips abandon intact young trends without changing any trading output.
+
+**Architecture:** Build immutable TimeSpace state and flip observations from frozen 4h exports, then mature fixed-horizon counterfactual labels in a separate attribution pipeline. The module consumes existing Alpha and execution evidence read-only, writes independent artifacts, and is mechanically barred from production imports.
+
+**Tech Stack:** Python 3.12, frozen dataclasses, NumPy/pandas only in the offline runner, existing architecture experiment exports, pytest, JSON artifacts.
+
+**Spec:** `docs/superpowers/specs/2026-08-23-time-space-shadow-design.md` plus registration governance in `docs/superpowers/specs/2026-08-24-trend-participation-two-layer-design.md`.
+
+## Global Constraints
+
+- Primary population is an A1_SIGN `alpha_flip` in the same UTC week as its old-side breakout, with old-side structure `INTACT` and zero source gaps.
+- Primary label is fixed-1x `hold_minus_flip_6`; horizons 1/2/3 are descriptive.
+- A current-bar pivot cannot define a same-bar breakout; boundaries are visible at `t-1`.
+- Shadow OFF/ON must leave snapshots, targets, orders, fills, equity, and episodes byte-identical.
+- 2025 is discovery-only; 2026 is reused diagnostic; confirmation requires trusted dual receipts, 180 elapsed days, 30 matured flips, and a market-state transition.
+- No field is added to domain models, A1-A5 rows, strategy, risk, or execution.
+- Each task gets a fresh implementation subagent, spec reviewer, and code-quality reviewer.

+@dataclass(frozen=True, slots=True)
+class TrendParticipationResearchIntent:

+def project_research_target(
+    latent_target: int,
+    current_filled: float,
+    safety: ResearchSafetySnapshot,
+    *,
+    decision_cutoff_ns: int,
+) -> float:
+    if safety.available_at_ns > decision_cutoff_ns:
+        raise ValueError("safety available_at_ns exceeds decision cutoff")
+    if safety.kill or safety.unsafe:

+    return float(latent_target)

+def verify_github_receipt(envelope: Mapping[str, Any], provider: Mapping[str, Any]) -> RegistrationReceipt:
