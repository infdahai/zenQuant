# 长期市场探索实验室

本轮依据用户2026-10-05的执行授权开展，12个方向各由独立subagent负责；适合一台Mac、无新增服务或依赖。
设计见 [实验合同](superpowers/specs/2026-10-05-market-exploration-design.md)，目录见
[方向注册表](../config/research/market_exploration_v1.json)。生产运行规格仍以
[LIVE_VALIDATION_HANDOFF_SPEC.md](LIVE_VALIDATION_HANDOFF_SPEC.md)为准。

## 系统边界

```mermaid
flowchart LR
    A[冻结假设和预算] --> B[来源审计与因果输入快照]
    B --> C[每方向独立实验]
    C --> D[哈希与attempt账本]
    D --> E[统一审核和研究优先级]
```

复用现有严格身份hash与TrialJournal。公共helpers只负责因果特征、时间分区、小型固定ridge基准和证据检查。
模型、机制或市场的实验互相隔离；没有引入通用agent runtime、数据库、调度服务或新交易路径。
本轮结果不能调用旧暂停campaign、写入optimizer、改变OptionsState乘数、晋级或真实下单。

## 运行

已安装的 `.venv` 即可。公共BTC输入源默认是2026-10-04修复的隔离4h数据，缺失时失败而不是退回有问题的旧数据。
2026记录只存在于源文件中；导出的learner快照不含2026。源文件读取不构成历史知识时间证明。

```bash
# 新目录冻结输入；同目录身份不匹配会拒绝。
.venv/bin/python scripts/run_market_exploration.py --prepare --output results/market_exploration/manual_001

# 一次direction attempt，不能覆盖既有attempt。
.venv/bin/python scripts/run_market_exploration.py --direction d01 --output results/market_exploration/manual_001

# 所有方向顺序运行，降低Mac峰值资源；日志建议写入新输出目录。
.venv/bin/python scripts/run_market_exploration.py --all --output results/market_exploration/manual_002

# 汇总同名attempt，失败/缺失方向保留在分母。
.venv/bin/python scripts/run_market_exploration.py --summarize --output results/market_exploration/manual_002
```

测试：

```bash
.venv/bin/python -m pytest -q tests/test_frontier_lab.py tests/test_frontier_d*.py
.venv/bin/python -m zenquant.app.check
```

Shell中的测试glob只匹配本轮12方向测试。完整gate中可能包含既有失败；不通过不允许宣称仓库已验收。

## 扩展与判断

修改新注册表中的固定参数、方向或seed时使用新campaign目录；每方向模块实现`run(context)`。
公共接口不会自动证明个别算法的因果性，必须保留边界/反例测试与独立review。
每方向应回答：假设、市场状态、输入、动作/目标、风险约束、失败案例、评估指标、否定条件、下一实验。

证据只有四类：真实历史诊断、合成机制、数据审计、混合。合成实验可以排除不合理机制，不能证明交易alpha。
模型预测指标与交易净收益分别看；执行时延、队列、订单生命周期、保证金和缺失数据尚未证明时，不把预测提升转成盈利承诺。
12方向形成探索选择偏差；五固定seed不是正式稳健性验收；2024–2025开发数据已反复观察，不是全新OOS。
研究优先级是下一步投入顺序，不能解释为策略排名或交易建议。

下一轮应先冻结少量保留假设，再设计独立确认窗口和前瞻采集；大模型、付费期权数据及实盘基础设施根据该证据决定。
