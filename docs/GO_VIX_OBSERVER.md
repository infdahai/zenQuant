# Go VIX observation

This read-only tool compares monthly VX futures and VIX9D/VIX index values in independent panels. It never produces trading intent, account risk decisions, forecasts, or orders. Demonstration prices are invented. READY applies only at the supplied cutoff; it does not establish present freshness, accuracy, licensing, or source authenticity.

## Run

Build the UI and binary with `make build`, then run `./bin/zenquant serve --engineering --port 8092` and open `http://127.0.0.1:8092/risk`. The page offers seven synthetic scenarios and accepts an exact observation request. `POST /api/vix/demo` and `POST /api/vix/evaluate` use the same loopback protections as the existing workbench. Example input: `internal/options/vix_demo.json`. The full JSON can also be evaluated with `zenquant evaluate --route /api/vix/evaluate < internal/options/vix_demo.json`.

To admit a retained local snapshot, run `zenquant vix-snapshot --request request.json --manifest manifest.json --evidence evidence-directory`. The manifest schema is `vix-snapshot-manifest.rust.v1`, with `time_basis` `SOURCE_EFFECTIVE_TIMESTAMP`, `rights` containing `status`, `reference`, `evidence_sha256`, `local_compute`, `local_display`, `retain_raw`, and `files` containing `filename` and `sha256`. Status is `SYNTHETIC_TEST_ONLY` for demonstration mode or `DECLARED_AUTHORIZED_LOCAL_ONLY` for supplied snapshots. All three permissions must be true. The rights evidence, calendar source, and every supplied quote source must identify pinned local bytes. Files are flat, regular, non-symlink files, at most 32 files, 16 MiB each and 64 MiB total; path components may not be symlinks. Date-only timing is rejected. This checks byte integrity and supplier declarations, not projection fidelity or rights, and grants no redistribution permission.

The calendar provides explicit settlement dates and last-trade times; the earliest two unexpired consecutive monthly contracts are selected, excluding weekly contracts. At exact last-trade time the old contract is excluded. No expiry schedule or missing price is inferred. Quote age is measured from observation, and synchronized session and observation times are required. Prices and spreads use exact decimals; nonterminating ratios retain their numerator and denominator with `decimal_exact: null`.

## Source and limitations

The port is based on [PR #23](https://github.com/infdahai/zenQuant/pull/23), source commit [c9c35a708b0286effc530fdc0919823d8caa9d8f](https://github.com/infdahai/zenQuant/tree/c9c35a708b0286effc530fdc0919823d8caa9d8f). The original [source research](https://github.com/infdahai/zenQuant/blob/c9c35a708b0286effc530fdc0919823d8caa9d8f/docs/VIX_SNAPSHOT_SOURCE_RESEARCH_20261022.md) and [Rust acceptance evidence](https://github.com/infdahai/zenQuant/tree/c9c35a708b0286effc530fdc0919823d8caa9d8f/docs/reports) document the original implementation, not validation of this Go port. Source research identifies the [CFE expiration notice](https://cdn.cboe.com/resources/product_update/2026/Correction-CFE-Futures-Contract-Expirations-for-Current-Products-to-be-Added-in-January-2026.pdf), [daily settlements](https://www.cboe.com/markets/us/futures/market-statistics/settlement/futures/daily/), and [market data policies](https://cdn.cboe.com/resources/membership/Market_Data_Policies.pdf); public availability does not establish licensing. No licensed live feed or real snapshot has been validated here.

Wire differences from Rust include Go source identity in `code_sha256`, a null `cargo_lock_sha256`, and an added `implementation` field. The source hash covers embedded Go options sources and the synthetic fixture. This port has not been established as byte-for-byte or full behavioral parity with Rust; use the Go tests for Go evidence. The browser retains no historical data and performs no financial calculations. Offline admission output is not itself a verified market data feed.
